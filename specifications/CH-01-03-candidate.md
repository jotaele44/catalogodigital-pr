# Evidence and identity candidate (CH-01–03)
Experimental additive contract; not wired into connect() or publication. Existing schema v2 remains unchanged. The fixture tests use in-memory databases only. Receipt records are immutable under ordinary SQL DML; privileged schema changes, raw file changes, direct SQL inserts and untrusted source authenticity are not solved. Byte digest verification is performed by the application, not by the SQL engine. Binding requires receipt source identity and reverified bytes; this proves neither source authority nor assertion semantics. No live acquisition, migration, rights certification or AFK claim. Further work must add typed authority/entity constraints, append-only conflict/supersession events, external content-addressed storage and integration with schema digest and authorization.
