# Boundary hardening candidate
Fixture installation enables recursive triggers to reject replacement of protected rows through ordinary SQL on that connection. This is not a privilege boundary; PRAGMA changes, privileged DDL and raw database writes remain outside the guarantee. Current-version uniqueness is checked on lifecycle events; direct relationship manipulation and legacy status projection require further integration. Parent deletion of event-managed versions is blocked. Rights resolution is conservative assertion intersection, not a legal determination. Temporal validation supports closed offset-aware intervals and explicit unknown only. No schema migration, publication, live source verification or version promotion claimed.
