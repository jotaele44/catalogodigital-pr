# Backup and CMR candidate
Backup is explicit, bounded, non-overwriting, and validated against a read transaction. Restore is to a new file only. Receipt is returned to caller; durable independent receipt storage, directory fsync, symlink/hostile filesystem controls, concurrency/crash tests, and backup-to-migration lock coupling remain open. No production migration. CMR adapter is metadata-only with fixed HTTPS host, disabled redirects, bounded page size/count/response bytes and timeout. Keyword results are discovery candidates, not Puerto Rico geographic verification. Pagination count matching is not snapshot completeness. Live source bytes and receipts have not been acquired. Default application entrypoint remains v2 until conversion is qualified.
